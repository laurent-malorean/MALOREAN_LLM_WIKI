# Règles — Objet métier

> Les chemins ci-dessous sont relatifs à la racine du thème (`data/wiki/themes/{theme}/`).

## Définition

Un objet métier est une entité manipulée dans le domaine ou dans le produit.

Exemples :

- équipement ;
- tâche ;
- demande d'intervention ;
- plan de maintenance ;
- pièce détachée ;
- document réglementaire.

## Emplacement

notes/objets-metier/

OBJ
