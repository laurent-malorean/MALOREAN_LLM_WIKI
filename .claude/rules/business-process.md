# Règles — Processus métier

> Les chemins ci-dessous sont relatifs à la racine du thème (`data/wiki/themes/{theme}/`).

## Définition

Une fiche processus décrit un enchaînement d'activités métier.

Elle documente :

- étapes ;
- acteurs ;
- entrées ;
- sorties ;
- décisions ;
- données ;
- preuves ;
- normes liées ;
- objets métier manipulés ;
- irritants ;
- implications produit.
