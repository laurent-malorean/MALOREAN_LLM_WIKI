# /wiki-search

Utiliser le skill `.claude/skills/wiki-search/SKILL.md`.

Objectif :

- analyser un besoin exprimé en langage libre ;
- identifier les concepts centraux et sous-jacents ;
- interroger la base RAG avec des requêtes sémantiquement riches ;
- produire une réponse structurée classée par pertinence (glossaire, notes atomiques, navigation).

Syntaxe :

```
/wiki-search {besoin exprimé librement}
/wiki-search --theme {theme} {besoin exprimé librement}
```
