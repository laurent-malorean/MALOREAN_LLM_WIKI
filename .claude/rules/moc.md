# Règles — MOC

> Les chemins ci-dessous sont relatifs à la racine du thème (`data/wiki/themes/{theme}/`).

## Définition

Un MOC est une carte de navigation.

Il organise les liens entre artefacts.

Un MOC n'est pas une note atomique.

## Emplacement

notes/moc/

## Préfixe

MOC

## Format

---
uid: ""
id: "MOC00000"
type: "moc"
status: "draft"
created: "YYYY-MM-DD"
updated: "YYYY-MM-DD"
title: ""
domain: []
source_ids: []
confidence: "medium"
---
